# Daily Standup Reports

> Generated by **Scrum Master Agent**  
> Triggered every morning or on-demand via the daily run command.

## File Naming Convention
- `docs/daily-reports/YYYY-MM-DD.md`

## Report Structure
1. **Executive Summary**
2. **Yesterday's Completed Deliverables** (Derived from git history & task runners)
3. **Today's Sprint Agenda & Task Allocations** (Assigned to Frontend Lead & Backend Lead)
4. **QA & Test Health Status** (Unit & E2E metrics from QA Lead)
5. **Blockers & Impediments**
